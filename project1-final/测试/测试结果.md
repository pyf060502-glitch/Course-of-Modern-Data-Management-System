# 测试结果

## 1. 环境与执行方式

测试使用Node.js 20、Node内置测试运行器、Supertest及真实MongoDB。数据库支持模块为每次测试生成survey_test_前缀随机库，校验库名和URI，仅清理自身数据；不使用业务账户或回答进行验收。

在code/执行完整回归：

```powershell
node --test --test-reporter=spec tests
```

浏览器使用本机Chrome、独立提供的Playwright-core及`code/scripts/check-question-library-browser.js`；运行方法见[测试用例](测试用例.md)。浏览器交互不属于默认npm test的一部分。

## 5. 结论与边界

已执行的自动化及Chrome流程均通过。持久化集成使用真实MongoDB；前端组件使用VM/简化DOM，部分并发测试包装真实数据库方法控制时机。HTTP重启用例证明所覆盖的原有实体及会话持久化，不等同于完整灾难恢复。

未验证生产TLS/代理信任、跨浏览器、压力性能和所有输入组合。通知接受、题库合并/归档与删除非跨集合事务；跨卷统计多次聚合非一致性事务快照。共同历史和使用查询按用户汇总，容量及规模边界见[数据库设计](../文档/数据库设计.md)。

该文件记录已完成的程序验收结果；文档编排调整不作为重新执行程序测试的证据。
