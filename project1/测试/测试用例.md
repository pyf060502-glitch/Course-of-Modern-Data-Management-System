# 测试用例

## 执行约定

本文件对应2026-10-22执行的完整 **88/88** 测试。程序位于 `code/`，在该目录执行以下命令；MongoDB实例需要提前启动。数据库测试创建随机专用库，不使用业务库，不清理未知库。

```powershell
$env:TEST_MONGODB_URI = 'mongodb://127.0.0.1:27027'
$env:TEST_MONGODB_DB = 'survey_test_integration'
npm test
```

下表逐项列出实际测试输入、步骤和预期结果，判定及耗时见[测试结果](测试结果.md)，完整运行输出见[自动化测试输出](自动化测试输出.log)。本次88项均通过，包括81个顶层测试和7个管理子测试。T76是包含T77～T83的父测试，也由运行器计入总数。
